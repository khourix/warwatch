# Fonts

Self-hosted, so the app loads no font from another site. Each file is a variable font; `styles.css` declares the weights.

| File | Family | Use | Source | Licence |
| --- | --- | --- | --- | --- |
| `switzer-normal.woff2` | Switzer | the interface | Indian Type Foundry, [fontshare.com](https://www.fontshare.com/fonts/switzer) | ITF Free Font Licence (Fontshare) |
| `sentient-normal.woff2`, `sentient-italic.woff2` | Sentient | the dispatch sentence and summaries | Indian Type Foundry, [fontshare.com](https://www.fontshare.com/fonts/sentient) | ITF Free Font Licence (Fontshare) |
| `jet-brains-mono-normal.woff2` | JetBrains Mono | ids, coordinates, dates, eyebrow labels | JetBrains, [github.com/JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono) | SIL Open Font Licence 1.1 |

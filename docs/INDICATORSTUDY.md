# Which indicators rose before events

Written by `warwatch/indicatorstudy.py`. No model and no tuning: each tracked series is scored day by day as the live build scores it, turned to the warning direction, and pooled into its family. For each event the highest z in the 30 days before it is compared with the same measure in calm 30-day windows of the same theatre. Events from 2019 on, after merging any within 30 days of an earlier one in the same theatre: 119 (54 from `events.csv`, 65 from `events_added.csv`). A family is only scored on events that fall after its history starts.

**Hit** = z reached 2 in the 30 days before. **False-alarm rate** = share of calm windows where it did. **AUC** compares the 30-day maximum before events with calm windows (0.5 = no difference). **q** is the p-value corrected for testing 85 families at once (Benjamini-Hochberg). **Holds on both halves** means p < 0.05 on the original events and again on the added ones.

## Headline

- Families tested: 85. Significant after correction (q < 0.10): 0. Lead on both the original and the added events: 0.
